# httpx

HTTP prober / fingerprinting.

Key flags:

- `-l <file>` list of hosts/URLs
- `-title -tech-detect -status-code -web-server` fingerprinting
- `-follow-redirects`
- `-json` JSON output
- `-o <file>` output
