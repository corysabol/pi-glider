# uncover

Search-engine querying for hosts/subdomains.

Key flags:

- `-q <query>` query (e.g. `-q 'ssl:"example.com"'`)
- `-e <engine>` engines (shodan, censys, fofa, etc.)
- `-o <file>` output

Requires API keys in `~/.config/uncover/provider-config.yaml`.
