# naabu

Fast, concurrent port scanner.

Key flags:

- `-host <ip>` / `-list <file>` targets
- `-p <ports>` ports (e.g. `-p 80,443` or `-top-ports 1000`)
- `-rate <n>` packets per second
- `-silent` minimal output
- `-o <file>` output
